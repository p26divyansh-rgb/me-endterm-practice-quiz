# ME End-Term Practice Quiz

A self-contained, timed practice quiz for the IIMA Microeconomics (ME) End-Term exam (24 Sep 2025).

- 25 MCQs, grouped under their shared case passages
- 75-minute timer with start/pause/submit and autosave/resume
- Auto-graded using the exam's own scoring rule: +5 correct, +1 un-attempted, 0 wrong

Open `index.html` in any browser to take the quiz.
